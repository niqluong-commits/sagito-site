What to do with it

  1. Install Sagito, if you have not already.
  2. Open it and go to the grown-up area, at the bottom of the home screen.
  3. Choose Scan an invite for an invite, or Explorer cards → Private card swaps for a gift or a swap.
  4. Paste the code and follow what it says.

Codes run out. An invite lasts a day and a gift a few days, so if yours is refused as expired, just ask for another.

Is this safe?

A code carries only what it needs: for an invite, the household name the sender chose; for a gift, the sender's display name and which item was sent. Never an adult's name, never a location, never anything about how a child is getting on. It is ordinary text in a link, so treat one like a note passed in the playground rather than a sealed envelope.
